MkDocs Installation — Step by Step

From zero to running local docs server in under 10 minutes

Step 1 — Install Python & pip

Terminal · Ubuntu/Debian
BASH
# Verify Python version (3.8+ required)
python3 --version
# Python 3.11.6

# Install pip if not present
sudo apt update && sudo apt install python3-pip python3-venv -y

# Verify pip
pip3 --version
# pip 23.2 from /usr/local/lib/python3.11/dist-packages/pip (python 3.11)

Step 2 — Create Virtual Environment (Best Practice)

Project Setup
BASH
# Create project directory
mkdir xyz-devops-docs && cd xyz-devops-docs

# Create virtual environment
python3 -m venv .venv

# Activate it
source .venv/bin/activate     # Linux/macOS
# .venv\Scripts\activate      # Windows PowerShell

# Your prompt now shows: (.venv)
(.venv) user@server:~/xyz-devops-docs$

Step 3 — Install MkDocs + Material Theme + Plugins

requirements.txt approach
BASH
# Install all at once (recommended)
pip install \
  mkdocs \
  mkdocs-material \
  mkdocs-git-revision-date-localized-plugin \
  mkdocs-minify-plugin \
  mkdocs-awesome-pages-plugin \
  mkdocstrings \

# Save dependencies to requirements file
pip freeze > requirements.txt

# Verify installation
mkdocs --version
mkdocs, version 1.5.3 from /home/user/xyz-devops-docs/.venv/lib/python3.11/site-packages/mkdocs (Python 3.11)

docs/08-runbooks/ssl-renewal.md
MARKDOWN
# SSL Certificate Renewal Runbook

!!! info "Overview"
    **Purpose:** Renew GoDaddy SSL certificate on production Nginx
    **Frequency:** Annually (30 days before expiry)
    **Owner:** DevOps Team | **Downtime:** None (zero-downtime reload)

## Pre-requisites

- [x] Access to GoDaddy dashboard
- [x] SSH access to production server
- [x] Sudo privileges on server
- [ ] (Leave unchecked — do at runtime)

## Step 1: Check Current Expiry

```bash
echo | openssl s_client -connect yourdomain.com:443 2>/dev/null \
  | openssl x509 -noout -dates
```

!!! warning "Alert Threshold"
    If **days remaining < 30**, proceed immediately with renewal.

## Step 2: Generate New CSR

```bash title="Generate CSR (reuse existing key)"
sudo openssl req -new \
  -key /etc/ssl/godaddy/yourdomain.key \
  -out /etc/ssl/godaddy/renewal.csr
```

## Architecture Diagram

```mermaid
sequenceDiagram
    participant DevOps
    participant GoDaddy
    participant Server
    DevOps->>GoDaddy: Submit CSR
    GoDaddy-->>DevOps: New certificate
    DevOps->>Server: Upload + combine cert
    Server-->>DevOps: nginx reload success
```

## Validation Checklist

| Check | Command | Expected |
|-------|---------|----------|
| Cert expiry | `openssl ... -dates` | New date 1y+ |
| Nginx syntax | `nginx -t` | syntax ok |
| HTTPS works | `curl -I https://domain` | 200 OK |

!!! success "Completion"
    Certificate successfully renewed. Update the expiry date in
    [Server Inventory](../02-infrastructure/server-inventory.md).

GitHub Actions CI/CD Pipeline

Auto-deploy on every push to main — zero-touch documentation deployment

Full Workflow File

.github/workflows/deploy.yml
YAML
name: Deploy MkDocs to GitHub Pages

on:
  push:
    branches:
      - main                  # Trigger on push to main
  pull_request:
    branches:
      - main                  # Build check on PRs (no deploy)
  workflow_dispatch:         # Allow manual trigger from GitHub UI

# Allow only one concurrent deployment
concurrency:
  group: "pages"
  cancel-in-progress: true

permissions:
  contents:  write            # Push to gh-pages branch
  pages:     write
  id-token:  write

jobs:

  # ── Job 1: Build & Validate ─────────────────────────────────
  build:
    runs-on: ubuntu-latest
    steps:

      - name: Checkout repository
        uses: actions/checkout@v4
        with:
          fetch-depth: 0        # Full history for git-revision dates

      - name: Set up Python 3.11
        uses: actions/setup-python@v5
        with:
          python-version: "3.11"
          cache:          "pip"   # Cache pip packages

      - name: Install MkDocs + plugins
        run: pip install -r requirements.txt

      - name: Build docs (validate)
        run: mkdocs build --strict --verbose
        # --strict: treat warnings as errors
        # Catches broken links, missing pages

      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: site/

  # ── Job 2: Deploy (only on push to main) ───────────────────
  deploy:
    needs: build
    runs-on: ubuntu-latest
    if: github.event_name == 'push' && github.ref == 'refs/heads/main'
    environment:
      name: github-pages
      url:  ${{ steps.deployment.outputs.page_url }}
    steps:

      - name: Deploy to GitHub Pages
        id:   deployment
        uses: actions/deploy-pages@v4

      - name: Print live URL
        run:  echo "✅ Docs live at ${{ steps.deployment.outputs.page_url }}"

📌 Naming Conventions

  • Prefix folders with numbers: 01-getting-started/
  • Kebab-case filenames: ssl-renewal.md
  • Post-mortems: YYYY-MM-DD-incident-name.md
  • Runbooks: imperative verb — restart-nginx.md
  • Every folder must have index.md

🏷️ Doc Metadata (Front Matter)

  • Add --- YAML front matter to every page
  • Include: title, description, author, date
  • Tags for searchability: tags: [nginx, ssl, production]
  • Status badges: draft / review / stable

🔍 Make Docs Searchable

  • Use consistent terminology across all docs
  • Add tags to every page
  • Write descriptive H2/H3 headings
  • MkDocs Material search is built-in and full-text

🔄 Keep Docs Fresh

  • Docs PR required for every infra change
  • Review docs quarterly in team sprint
  • git-revision-date plugin shows last updated
  • Mark stale docs with !!! warning "Needs review"
